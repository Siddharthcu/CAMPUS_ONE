Clone the repository and enter the project folder:

```bash
git clone https://github.com/Siddharthcu/CAMPUS_ONE.git
cd CAMPUS_ONE
```

Install the dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

Open that address in your browser.
